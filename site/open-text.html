Free-text survey answers, shown as a filterable list rather than charted — they aren't structured data. Region and activity are shown as context, not as a claimed link to a specific programme.

No open-text responses in this data drop

open_text.csv is not present in ./data/, and the script that would produce it from the raw Qualtrics export (reshape_v3.py, referenced in the data contract) isn't in this drop either — so nothing has been invented to fill the gap.

This page is otherwise complete: once open_text.csv is added (columns ResponseId,question,source_column,response, per the data contract) and the build is re-run (node build/build.js), it will render here automatically — filterable by question, region and activity, with a theme column ready for coding.

Theme coding slots in the same way: add open_text_themes.csv with columns ResponseId,question,theme, keyed the same way as the responses themselves, and every row's theme column populates on the next build. Until that file exists, the column is present and shows "not yet coded".
